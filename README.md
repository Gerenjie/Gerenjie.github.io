# gerenjie.github.io

Personal site of Jake Kurlander. Plain static HTML, served by GitHub Pages; no build step.

- `index.html` — the whole site
- `assets/hero.js` — the animated hero (every Rubin/X05-discovered minor planet, two-body propagation)
- `assets/x05-data.js` — packed orbital elements (gzip + base64), same format as the /x05-orrery/ repo
- `assets/*.jpg` — photos

To edit: change `index.html`, commit, push. The site updates in about a minute.
